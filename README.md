# MarketMinds — Digital Marketing & Growth Agency

A marketing and growth agency website for **MarketMinds**, led by **Dhruv Verma**. Built with React 19, Vite, Tailwind CSS, Framer Motion, and Three.js.

---

## ✨ Features

- **Responsive Multi-Page Architecture** — Home, About, Services, Pricing, Approach, Contact, and Legal Compliance pages.
- **Interactive 3D WebGL Background** — Ambient liquid-gold wireframe terrain built on Three.js.
- **Dark / Light Theme** — Seamless theme toggle with persistent preferences.
- **Lead Capture** — Contact form with client-side validation and anti-spam protection.
- **Accessible & Performance Optimized** — Semantic HTML5 structure, lazy-loaded components, and responsive typography.

---

## 🛠 Tech Stack

- **Frontend**: React 19, Vite, React Router 7
- **Styling**: Tailwind CSS 3
- **Animations**: Framer Motion
- **3D Graphics**: Three.js, `@react-three/fiber`
- **Icons**: Lucide React
- **Hosting**: Vercel

---

## 🚀 Getting Started

Requires **Node.js 20+**.

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build

# Run linter
npm run lint
```
